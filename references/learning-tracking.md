## 一、追踪体系概述

### 核心目标

| 目标 | 说明 |
|-----|------|
| 可视化成长 | 让用户清晰看到自己的思维模型学习进度 |
| 发现薄弱点 | 识别使用频率低或掌握度不足的场景和模型 |
| 个性化推荐 | 基于薄弱环节智能推荐下一步学习内容 |
| 强化动力 | 通过阶段性报告和成就系统维持学习动力 |
| 效果验证 | 评估思维模型在实际问题中的应用效果 |

### 追踪层级

```
层级1：场景级追踪（9个场景的使用频率和效果）
  |
层级2：模型级追踪（94个模型的掌握度和使用频率）
  |
层级3：会话级追踪（每次教练对话的详细记录）
```

## 二、9大场景训练记录维度

### 场景训练记录表

每次使用某个场景时，记录以下维度：

| 维度 | 字段名 | 类型 | 说明 |
|-----|-------|------|------|
| 场景编号 | scenario_id | string | S01-S09 |
| 场景名称 | scenario_name | string | 如"认知纠偏" |
| 使用时间 | timestamp | datetime | 使用时间 |
| 问题摘要 | problem_summary | text | 用户问题的简要描述 |
| 问题类型 | problem_type | string | 决策类/学习类/分析类/沟通类/创新类 |
| 使用的模型 | models_used | array | 本次使用的模型列表 |
| 主要模型 | primary_model | string | 本次最核心的模型 |
| 对话轮次 | rounds | number | 教练对话的轮次数 |
| 完成度 | completion | number | 0-100%，流程完成程度 |
| 用户满意度 | satisfaction | number | 1-5分，用户自评 |
| 效果自评 | effectiveness | number | 1-5分，用户觉得有没有帮助 |
| 关键产出 | key_output | text | 本次对话的核心结论/行动 |

| 评估指标 | 计算方式 | 薄弱阈值 |

## 四、训练效果评估方法

### 4.1 单次会话效果评估

每次教练对话结束后，从以下4个维度评估效果：

| 维度 | 评估问题 | 评分方式 |
|-----|---------|---------|
| **清晰度** | "这次对话后，你对问题的理解更清晰了吗？" | 1-5分 |
| **实用性** | "你获得了可以立即行动的具体建议吗？" | 1-5分 |
| **新颖性** | "这次对话有没有给你带来新的视角或启发？" | 1-5分 |
| **满意度** | "总体来说，你对这次教练体验满意吗？" | 1-5分 |

综合效果分 = (清晰度 x 0.3 + 实用性 x 0.3 + 新颖性 x 0.2 + 满意度 x 0.2)

### 4.2 阶段性效果评估（每10次会话）

| 评估维度 | 评估方法 | 评估标准 |
|---------|---------|---------|
| **思维广度** | 使用过的不同模型数量 | 目标：累计使用30+个不同模型 |
| **思维深度** | 单个模型的使用深度（能否灵活应用） | 目标：5+个模型达到"熟练"级别 |
| **独立应用** | 不需要教练提示就能主动选择模型 | 目标：最近5次中3+次主动选择 |
| **组合能力** | 能否在一个问题中组合使用多个模型 | 目标：2+次成功组合使用 |
| **实际效果** | 用户自评思维模型对实际工作/生活的帮助 | 目标：平均效果评分 > 4.0 |

### 4.3 长期效果评估（每30次会话）

| 评估维度 | 评估方法 |
|---------|---------|
| **决策质量提升** | 对比前后决策的理性程度（自我评估+回访） |
| **问题解决能力** | 解决复杂问题的速度和质量是否提升 |
| **认知偏差减少** | 在日常判断中是否更少受偏差影响 |
| **知识迁移** | 能否将思维模型应用到新的领域 |
| **教学能力** | 能否向他人解释和使用这些模型 |

### 4.4 效果评估问卷模板

```
请对以下陈述打分（1=完全不同意，5=完全同意）：

1. 思维模型帮助我更客观地分析问题
2. 思维模型帮助我做出了更好的决策
3. 我能在日常生活中主动运用思维模型
4. 思维模型改善了我的工作表现
5. 我能向同事/朋友解释这些思维模型
6. 我希望继续学习和使用思维模型
7. 思维模型教练的引导方式适合我
8. 整体来说，思维模型训练对我的帮助很大
```

## 六、智能推荐逻辑

### 6.1 基于薄弱场景的推荐

**触发条件**：某场景使用次数 < 总次数的5%，或连续20次会话未使用

**推荐逻辑**：

```
IF 场景X使用率 < 5%:
    优先级 = HIGH
    推荐理由 = "你还没有充分练习[场景名称]"
```

### 6.4 基于学习阶段的推荐

## 七、数据存储与隐私

### 存储结构

| 数据类型 | 存储位置 | 保留时间 |
|---------|---------|---------|
| 会话记录 | 对话上下文 | 当前会话 |
| 用户档案 | 对话上下文（跨会话保持） | 持久 |
| 学习统计 | 对话上下文 | 持久 |
| 导出报告 | /workspace/ 目录 | 永久（用户触发时） |

### 数据隐私原则

1. **本地存储**：所有数据仅存储在用户本地，不上传到任何外部服务
2. **用户控制**：用户可随时查看、导出或清除所有学习数据
3. **最小采集**：只采集与学习追踪直接相关的数据
4. **匿名分析**：任何分析报告都不包含可识别个人身份的信息
5. **清除命令**：用户可通过指令清除所有历史数据

### 数据导出格式

用户可随时导出学习数据，支持以下格式：
- JSON格式：完整的结构化数据
- Markdown格式：可读的学习报告
- CSV格式：模型掌握度表格
