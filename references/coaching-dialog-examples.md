# 教练对话示例库

本文档记录各类场景的教练对话示例，供参考和复用。

## 示例1：业绩下滑汇报

### 用户问题
"最近要跟领导汇报销售业绩下滑，特殊专项营销活动成绩为零，怎么汇报？"

### 教练对话过程

#### Phase 0: 问题识别

```
教练：你面临一个向上汇报困难局面的挑战。核心诉求是：如何既诚实汇报，
又展现你的分析和改进能力，避免被"一棍子打死"。

推荐思维模型组合：
- 主模型：GROW教练模型 — 结构化对话
- 辅助模型：根因分析 — 找到"为什么"
- 辅助模型：二阶思维 — 预判领导反应
```

#### G阶段：目标

```
教练：在我们开始之前，我需要通过几个问题帮你真正想清楚目标。

问题1：这次汇报，你最想达成的首要目标是什么？
问题2：理想结果是什么？请用一两句话描述
问题3：底线是什么？最差能接受什么？

用户回答：
1. A - 让领导了解真实情况，争取理解和支持
2. 领导理解并协助提供改进建议
3. 最差的情况就是重新分析并复盘

教练提炼：
| 维度 | 内容 |
|-----|------|
| 核心目标 | 如实呈现数据 + 主动分析原因，展现"我在解决问题"的姿态 |
| 理想结果 | 领导从"追责模式"转为"共创模式" |
| 底线接受 | 即使被要求重来，也意味着给了机会而非直接否定 |
```

#### R阶段：现状

```
教练：现在进入最关键的一步：把事实和原因想清楚。

R-1：事实层面
① 数据事实：销售同比下滑30%，从3月开始，整体下滑
② 专项活动：重要时期保障咨询，目标100%成交，实际0转化，持续1个多月
③ 已做措施：拜访所有客户，积极响应需求，暂无效果

R-2：根因分析（分两条线）

线A：销售下滑
第1个为什么：商务侧人员大换血，新人入职晚，多次交接断层
第2个为什么：交接后没有跟进确认新人是否接得住
第3个为什么：公司/部门没有交接验收标准
第4个为什么：商务侧没有交接流程 + 对方不愿意完全交接
【根因】：交接机制缺失 + 交接意愿问题

线B：活动0转化
第1个为什么：跟进落后3周，情报没有收集
第2个为什么：周会有但没有情报汇报
第3个为什么：商务侧找不到情报来源
第4个为什么：渠道问题，没有打通关键监管单位
【根因】：关键渠道未打通 + 情报收集机制缺失
```

#### O阶段：选项

```
教练：现在进入O阶段：你有哪些选择？

O-1：策略选项
| 策略 | 做法 | 优点 | 风险 |
|-----|------|-----|------|
| 策略A | 全盘托出 | 诚实透明 | 可能得罪同事 |
| 策略B | 聚焦机制 | 建设性强 | 可能被追问 |
| 策略C | 先外后内 | 渐进呈现 | 可能被认为找借口 |

用户选择：策略B

O-2：改进方案
用户选择：方案A1（建立交接验收清单）+ 方案B2（打通监管单位渠道）

二阶思维预判：
一阶效应：领导看到你在分析问题、提方案
二阶效应：领导可能追问"为什么之前没机制"
需要准备：回答"之前人员稳定，问题不突出；这次暴露了短板"
```

#### W阶段：行动

```
教练：现在形成最终的汇报计划。

W-1：汇报框架
一、数据概览：销售同比下滑30%，从3月开始，整体下滑
二、原因分析：外部简述，内部重点（交接机制缺失、情报机制缺失）
三、改进方案：建立交接验收清单、打通监管单位渠道
四、预期与承诺：X周内落地，每两周汇报

W-2：关键话术
开场："领导，我来汇报一下...数据确实不太理想，但我已经做了分析..."
讲原因："外部有一定影响，但核心问题在内部..."
讲方案："针对这两个问题，我建议..."
结尾："后续我每两周向您汇报进展。"

W-3：改进计划
| 措施 | 具体动作 | 时间节点 | 责任人 |
|-----|---------|---------|-------|
| 建立交接清单 | 起草模板，对齐试运行 | 本周 | 用户 |
| 打通监管渠道 | 梳理名单，请求领导协调 | 本月 | 用户 |
```

## 示例2：项目延期汇报

### 用户问题
"项目又延期了，怎么跟客户解释？"

### 教练对话过程（简化版）

#### G阶段

```
教练：三个问题帮你明确目标：
1. 这次沟通的首要目标是什么？
2. 理想结果是什么？
3. 底线是什么？

用户：
1. 让客户理解延期原因，不要投诉
2. 客户接受新时间节点，继续合作
3. 最差是客户投诉但不解约
```

#### R阶段

```
教练：梳理事实和原因：
- 延期多久？什么原因？
- 之前承诺的时间节点是什么？
- 客户已经知道延期了吗？

根因分析：
第1个为什么：需求变更导致开发时间不够
第2个为什么：变更没有走评估流程
第3个为什么：没有变更管理机制
【根因】：变更管理机制缺失
```

#### O阶段

```
教练：策略选项：
| 策略 | 做法 |
|-----|------|
| A | 主动告知+原因+补救方案 |
| B | 等客户问再解释 |

建议选择A：主动沟通展现诚意

改进方案：
- 短期：加班追赶进度
- 中期：建立变更管理流程
```

#### W阶段

```
教练：沟通框架：
1. 主动告知延期事实
2. 解释原因（不甩锅）
3. 提出补救方案和新时间节点
4. 承诺后续改进

关键话术：
"关于项目进度，有个情况需要跟您同步一下..."
"延期的主要原因是...，我们已经在..."
"新的交付时间是...，我们会..."
"后续我们会建立变更管理机制，避免类似情况..."
```

## 示例3：拒绝客户需求

### 用户问题
"客户提出了一个不合理的需求，怎么拒绝？"

### 教练对话过程（简化版）

#### G阶段

```
教练：明确目标：
1. 拒绝需求但维护关系
2. 理想：客户理解并接受替代方案
3. 底线：客户不满但不流失
```

#### R阶段

```
教练：分析情况：
- 需求具体是什么？为什么不合理？
- 客户为什么提这个需求？背后诉求是什么？
- 有没有替代方案？

根因分析：
客户需求不合理的背后，可能是[真实诉求]没有被满足
```

#### O阶段

```
教练：策略选项：
| 策略 | 做法 |
|-----|------|
| A | 直接拒绝+说明原因 |
| B | 先肯定+再解释困难+提替代方案 |
| C | 拖延战术 |

建议选择B：先肯定再引导
```

#### W阶段

```
教练：沟通话术：
"我理解您希望...（肯定诉求）"
"这个需求我们评估了一下，主要困难是...（解释原因）"
"不过我们有个替代方案，可以...（提出替代）"
"您看这样是否可以解决您的问题？"

如果客户坚持：
"我理解您的考虑，让我回去再评估一下，X天内给您答复"
（给自己缓冲时间）
```

## 通用话术模板库

### 开场话术

| 场景 | 话术 |
|-----|------|
| 汇报坏消息 | "有个情况需要跟您汇报一下...数据确实不太理想，但我已经做了分析..." |
| 承认错误 | "这件事主要责任在我，我已经复盘了原因..." |
| 提出请求 | "有个事情想请您帮忙...具体是..." |

### 解释话术

| 场景 | 话术 |
|-----|------|
| 解释原因 | "主要原因是...，根本上是..." |
| 不甩锅 | "外部有一定影响，但核心问题在我们内部..." |
| 承认不足 | "这块确实是我们考虑不周，已经在改进..." |

### 提方案话术

| 场景 | 话术 |
|-----|------|
| 提出方案 | "针对这个问题，我建议：第一...，第二..." |
| 请求支持 | "另外...需要请您帮忙协调一下" |
| 承诺时间 | "X天内给您结果" |

### 结尾话术

| 场景 | 话术 |
|-----|------|
| 标准结尾 | "后续我每X周向您汇报进展" |
| 请求反馈 | "以上是我的想法，想听听您的意见" |
| 留有余地 | "如果还有其他考虑，我们再沟通" |
