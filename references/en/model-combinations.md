## Overview

### Why Combine Models?

Single thinking models often address only one facet of a problem. Complex real-world problems have multiple dimensions that require several models working together from different angles.

### Three Levels of Combination

```
Level 1: Single Model (Beginner)
  User brings a problem → Recommend 1 core model → Guide usage

Level 2: In-Scenario Combination (Intermediate)
  2-3 models within the same scenario, e.g., "Confirmation Bias + Anchoring Effect" for cognitive calibration

Level 3: Cross-Scenario Combination (Advanced)
  3-4 models across scenarios, e.g., "Root Cause Analysis + Systems Thinking + Second-Order Thinking" for complex diagnosis
```

### Trigger Conditions

| Trigger | Description | Example |
|---------|-------------|---------|
| Problem spans 2+ scenarios | Signal words match multiple scenarios | "Revenue decline, should we lay off?" → S03+S06+S07 |
| Problem is systemic | Contains "recurring", "always", "chain" | "Why does this keep happening?" → S03+S04 |
| Problem needs data validation | Involves data but needs judgment | "Data says A but I think B" → S05+S01+S06 |
| User requests it | User says "any better approach?" | "Can you help me analyze this comprehensively?" |
| User is advanced | Total usage >30, mastered 5+ models | Auto-recommend more complex combinations |

## 12 Classic Combinations

### C01: Deep Diagnosis (Complex Problem Analysis)
- **Models**: Root Cause Analysis (5 Whys) + Flywheel Effect + Confirmation Bias
- **Scenarios**: S03 Problem Solving + S04 Systems Insight + S01 Cognitive Calibration
- **Difficulty**: ⭐⭐⭐ Advanced
- **Logic**: Find root cause → Check for feedback loops → Verify objectivity
- **GROW Embedding**: Root Cause in R phase, Flywheel in O phase, Confirmation Bias in W phase

### C02: Rational Decision (Major Choices)
- **Models**: Decision Matrix + Sunk Cost Fallacy + First Principles Thinking
- **Scenarios**: S06 Decision Analysis + S01 Cognitive Calibration + S03 Problem Solving
- **Difficulty**: ⭐⭐⭐ Advanced
- **Logic**: Check for sunk cost bias → Strip to fundamentals → Quantify options

### C03: Data Judgment (Information Verification)
- **Models**: Correlation ≠ Causation + Availability Heuristic + Base Rate Fallacy
- **Scenarios**: S05 Data & Evidence + S01 Cognitive Calibration
- **Difficulty**: ⭐⭐ Intermediate
- **Logic**: Check causal claims → Check data availability bias → Calibrate with base rates

### C04: Conflict Resolution (Negotiation/Disputes)
- **Models**: Game Theory + Framing Effect + Reciprocity
- **Scenarios**: S07 Conflict Resolution + S08 Potential Release + S01 Cognitive Calibration
- **Difficulty**: ⭐⭐⭐ Advanced
- **Logic**: Reframe from win-lose to win-win → Analyze strategy space → Design reciprocal proposals

### C05: Rapid Learning (Skill Breakthrough)
- **Models**: Feynman Technique + Pareto Principle (80/20) + Deliberate Practice
- **Scenarios**: S02 Learning & Growth + S03 Problem Solving
- **Difficulty**: ⭐⭐ Intermediate
- **Logic**: Find the vital 20% → Teach it to learn it → Practice at the edge

### C06: Systems Thinking (Global Insight)
- **Models**: Systems Thinking (Flywheel + Inertia) + Second-Order Thinking + Inversion
- **Scenarios**: S04 Systems Insight + S03 Problem Solving + S06 Decision Analysis
- **Difficulty**: ⭐⭐⭐ Advanced
- **Logic**: Work backwards from desired outcome → Identify feedback loops → Predict cascading effects

### C07: Innovation Breakthrough (Finding New Solutions)
- **Models**: First Principles Thinking + Lateral Thinking + Redefine the Problem
- **Scenarios**: S03 Problem Solving + S02 Learning & Growth
- **Difficulty**: ⭐⭐⭐ Advanced
- **Logic**: Challenge problem definition → Decompose to fundamentals → Cross-pollinate from other fields

### C08: Risk Assessment (Pre-Action Evaluation)
- **Models**: Second-Order Thinking + Black Swan Events + Scenario Analysis
- **Scenarios**: S06 Decision Analysis + S05 Data & Evidence
- **Difficulty**: ⭐⭐⭐ Advanced
- **Logic**: Predict chain reactions → Imagine extreme cases → Build optimistic/neutral/pessimistic scenarios

### C09: Team Motivation (Management/Leadership)
- **Models**: Pygmalion Effect + Maslow's Hierarchy + Social Proof
- **Scenarios**: S08 Potential Release + S07 Conflict Resolution
- **Difficulty**: ⭐⭐ Intermediate
- **Logic**: Assess team needs level → Set high expectations → Leverage positive role models

### C10: Competitive Advantage (Business Strategy)
- **Models**: Economic Moat + Network Effects + Switching Costs
- **Scenarios**: S09 Market Strategy + S04 Systems Insight
- **Difficulty**: ⭐⭐⭐ Advanced
- **Logic**: Analyze moat sources → Evaluate network effects → Design switching cost barriers

### C11: Persuasive Reporting (Upward Communication)
- **Models**: Framing Effect + Sunk Cost Fallacy + Cost-Benefit Analysis
- **Scenarios**: S08 Potential Release + S01 Cognitive Calibration + S06 Decision Analysis
- **Difficulty**: ⭐⭐ Intermediate
- **Logic**: Design optimal framing → Leverage existing investments → Quantify ROI

### C12: Self-Breakthrough (Personal Growth)
- **Models**: Growth Mindset + Impostor Syndrome + Deliberate Practice
- **Scenarios**: S08 Potential Release + S02 Learning & Growth
- **Difficulty**: ⭐⭐ Intermediate
- **Logic**: Recognize impostor feelings → Reframe as growth opportunity → Design targeted practice

## Combination Workflow Guide

### Recommendation Template

When a combination is recommended, insert after Phase 0:

```
## 🔗 Model Combination Recommended

Your problem spans [Scenario A] + [Scenario B]. I recommend the [Combination Name]:

| Step | Model | Purpose | Est. Time |
|------|-------|---------|-----------|
| 1️⃣ | [Model A] | [Purpose] | 3-5 min |
| 2️⃣ | [Model B] | [Purpose] | 3-5 min |
| 3️⃣ | [Model C] | [Purpose] | 3-5 min |

💡 Why this combo: [Explanation]

Options:
- Type "start" to begin guided session
- Type "use [Model A] only" for single model
- Type /skip to use standard GROW flow
```

### GROW Phase Embedding Map

| GROW Phase | Best Model Types | Examples |
|-----------|-----------------|---------|
| R Phase | Analytical, Investigative | C01 Root Cause, C02 First Principles |
| O Phase | Expansive, Evaluative | C01 Flywheel, C06 Second-Order Thinking |
| W Phase | Validating, Actionable | C01 Confirmation Bias, C11 Framing Effect |

## Effect Evaluation

### Single Model Contribution (1-5 scale)

| Dimension | Criteria |
|-----------|----------|
| New Insight | Did this model reveal perspectives you hadn't considered? |
| Practicality | Can the output be directly applied to action? |
| Relevance | How relevant is this model to the problem? |
| Ease of Use | Was the model easy to apply in context? |

### Combination Synergy (1-5 scale)

| Dimension | Criteria |
|-----------|----------|
| 1+1>2 Effect | Is the combination more effective than individual models? |
| Logical Flow | Do the models connect naturally? |
| Completeness | Does the combination cover multiple aspects of the problem? |
| Time Efficiency | Was the time investment worthwhile? |
