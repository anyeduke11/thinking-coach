## 一、组合推荐概述

### 为什么需要模型组合？

单个思维模型往往只能解决问题的某个切面。复杂现实问题通常具有多维度特征，需要多个模型从不同角度协同分析，才能得出全面、可靠的结论。

### 组合的三个层次

```
层次1：单模型使用（入门）
  用户带着问题来，推荐1个核心模型引导使用

层次2：场景内组合（进阶）
  同一场景内2-3个模型协作，如"确认偏误+锚定效应"用于认知纠偏

层次3：跨场景组合（高级）
  跨场景3-4个模型串联，如"根因分析+系统思维+二阶思维"用于复杂问题诊断
```

### 组合推荐触发条件

| 触发条件 | 说明 | 示例 |
|---------|------|------|
| 问题涉及2+个场景 | 信号词匹配到多个场景 | "业绩下滑要不要裁员" → S03+S06+S07 |
| 问题具有系统性 | 包含"反复""总是""链条"等词 | "为什么总是出现同样的问题" → S03+S04 |
| 问题需要数据支撑 | 涉及数据但需要判断 | "数据说A方案好但我觉得B好" → S05+S01+S06 |
| 用户主动请求 | 用户说"有没有更好的方法" | "能不能帮我全面分析一下" |
| 用户已达进阶阶段 | 总使用>30次，掌握5+模型 | 自动推荐更复杂的组合 |

## 二、12个经典组合模板

### C01：深度诊断组合（复杂问题分析）

| 属性 | 说明 |
|-----|------|
| **组合名称** | 深度诊断 |
| **适用场景** | 复杂问题根因不明、反复出现的问题 |
| **涉及场景** | S03 问题解决 + S04 系统洞察 + S01 认知校准 |
| **模型组合** | 根因分析（5Why）+ 飞轮效应 + 确认偏误 |
| **难度等级** | ⭐⭐⭐ 高级 |
| **前置要求** | 用户已掌握根因分析（L2+） |

**组合逻辑**：
```
第1步：根因分析（5Why）
  → 找到表面原因 → 追问到根本原因
  
第2步：飞轮效应
  → 检查根因是否构成正反馈循环
  → 识别"增强回路"和"调节回路"
  → 判断问题是否会自我放大

第3步：确认偏误
  → 检查分析过程中是否只关注了支持某一结论的证据
  → 红队测试：尝试推翻当前结论
```

**教练引导话术**：
```
📊 检测到复杂问题，推荐【深度诊断组合】

这个问题看起来涉及多个层面，我建议用3个模型串联分析：

1️⃣ 先用「根因分析」找到根本原因
2️⃣ 再用「飞轮效应」检查是否构成循环
3️⃣ 最后用「确认偏误」验证结论的客观性

预计需要15-20分钟深度分析，准备好了吗？
```

### C02：理性决策组合（重大选择）

| 属性 | 说明 |
|-----|------|
| **组合名称** | 理性决策 |
| **适用场景** | 重大决策、多选项比较、高风险选择 |
| **涉及场景** | S06 决策分析 + S01 认知校准 + S03 问题解决 |
| **模型组合** | 决策矩阵 + 沉没成本谬误 + 第一性原理 |
| **难度等级** | ⭐⭐⭐ 高级 |
| **前置要求** | 用户已掌握决策矩阵（L2+） |

**组合逻辑**：
```
第1步：沉没成本谬误
  → 检查各选项是否受已投入成本影响
  → "如果从零开始，你还会选这个吗？"

第2步：第一性原理
  → 剥离所有假设，回到问题本质
  → "这个决策最核心要解决的是什么？"

第3步：决策矩阵
  → 列出所有选项
  → 设定评估维度和权重
  → 量化打分，得出推荐
```

### C03：数据判断组合（信息验证）

| 属性 | 说明 |
|-----|------|
| **组合名称** | 数据判断 |
| **适用场景** | 需要验证数据/报告/结论的可靠性 |
| **涉及场景** | S05 数据判断 + S01 认知校准 |
| **模型组合** | 相关性≠因果性 + 可得性偏差 + 基础比率谬误 |
| **难度等级** | ⭐⭐ 中级 |
| **前置要求** | 无 |

**组合逻辑**：
```
第1步：相关性≠因果性
  → 检查结论是否混淆了相关关系和因果关系
  → "A和B同时发生，不代表A导致了B"

第2步：可得性偏差
  → 检查数据来源是否容易被获取但不够代表性
  → "你看到的这些数据，是否只是最容易看到的？"

第3步：基础比率谬误
  → 用基准概率校准判断
  → "在类似情况下，通常的成功率是多少？"
```

### C04：冲突化解组合（谈判/矛盾处理）

| 属性 | 说明 |
|-----|------|
| **组合名称** | 冲突化解 |
| **适用场景** | 团队矛盾、客户投诉、谈判僵局 |
| **涉及场景** | S07 冲突应对 + S08 潜能释放 + S01 认知校准 |
| **模型组合** | 博弈论 + 框架效应 + 互惠 |
| **难度等级** | ⭐⭐⭐ 高级 |
| **前置要求** | 用户已掌握博弈论（L2+） |

**组合逻辑**：
```
第1步：框架效应
  → 分析当前沟通的框架是否加剧了冲突
  → 尝试重新框架问题（从"输赢"到"共赢"）

第2步：博弈论
  → 分析双方的利益诉求和策略空间
  → 识别是零和博弈还是非零和博弈
  → 寻找帕累托改进点

第3步：互惠
  → 设计互惠方案，先给予对方价值
  → 利用互惠心理建立合作基础
```

### C05：快速学习组合（技能突破）

| 属性 | 说明 |
|-----|------|
| **组合名称** | 快速学习 |
| **适用场景** | 需要快速掌握新技能/新领域 |
| **涉及场景** | S02 学习提升 + S03 问题解决 |
| **模型组合** | 费曼学习法 + 帕累托法则 + 刻意练习 |
| **难度等级** | ⭐⭐ 中级 |
| **前置要求** | 无 |

**组合逻辑**：
```
第1步：帕累托法则（80/20）
  → 找到该领域最核心的20%知识
  → "掌握哪些内容就能解决80%的问题？"

第2步：费曼学习法
  → 用自己的话解释核心概念
  → 找到理解卡壳的地方，重点突破

第3步：刻意练习
  → 设计针对性的练习方案
  → 在舒适区边缘持续挑战
```

### C06：系统思考组合（全局洞察）

| 属性 | 说明 |
|-----|------|
| **组合名称** | 系统思考 |
| **适用场景** | 需要看清全局、理解复杂系统运作 |
| **涉及场景** | S04 系统洞察 + S03 问题解决 + S06 决策分析 |
| **模型组合** | 系统思维（飞轮+惯性）+ 二阶思维 + 逆向思维 |
| **难度等级** | ⭐⭐⭐ 高级 |
| **前置要求** | 用户已掌握二阶思维（L2+） |

**组合逻辑**：
```
第1步：逆向思维
  → 从期望的终点倒推
  → "如果要让这个问题彻底解决，需要什么条件？"

第2步：系统思维（飞轮+惯性）
  → 识别系统中的增强回路和调节回路
  → 找到系统的"杠杆点"（最小干预产生最大效果的位置）

第3步：二阶思维
  → 预判干预措施的连锁反应
  → "做了X之后，会引发什么？引发之后又会怎样？"
```

### C07：创新突破组合（寻找新方案）

| 属性 | 说明 |
|-----|------|
| **组合名称** | 创新突破 |
| **适用场景** | 常规方法无效、需要创新解决方案 |
| **涉及场景** | S03 问题解决 + S02 学习提升 |
| **模型组合** | 第一性原理 + 横向思维 + 重新定义问题 |
| **难度等级** | ⭐⭐⭐ 高级 |
| **前置要求** | 用户已掌握第一性原理（L2+） |

**组合逻辑**：
```
第1步：重新定义问题
  → 检查当前问题定义是否限制了思路
  → "如果问题不是X而是Y，会有什么不同？"

第2步：第一性原理
  → 分解到最基本的事实和物理限制
  → 从基本事实重新构建方案

第3步：横向思维
  → 从不相关领域寻找灵感
  → "其他行业/领域是怎么解决类似问题的？"
```

### C08：风险评估组合（重要行动前的预判）

| 属性 | 说明 |
|-----|------|
| **组合名称** | 风险评估 |
| **适用场景** | 重要行动/投资/决策前的风险预判 |
| **涉及场景** | S06 决策分析 + S05 数据判断 |
| **模型组合** | 二阶思维 + 黑天鹅事件 + 情景分析 |
| **难度等级** | ⭐⭐⭐ 高级 |
| **前置要求** | 用户已掌握二阶思维（L2+） |

**组合逻辑**：
```
第1步：二阶思维
  → 预判行动的直接后果和连锁反应
  → 列出1阶、2阶、3阶效应

第2步：黑天鹅事件
  → 识别可能的极端情况
  → "如果发生最意想不到的事，会是什么？"

第3步：情景分析
  → 构建乐观/中性/悲观三种情景
  → 为每种情景准备应对方案
```

## 三、组合工作流引导

### 3.1 组合推荐话术模板

当检测到需要模型组合时，在 Phase 0 问题识别后插入：

```
## 🔗 模型组合推荐

你的问题涉及【场景A】+【场景B】，建议使用【组合名称】组合来深度分析：

| 步骤 | 模型 | 作用 | 预计时间 |
|-----|------|------|---------|
| 1️⃣ | [模型A] | [作用说明] | 3-5分钟 |
| 2️⃣ | [模型B] | [作用说明] | 3-5分钟 |
| 3️⃣ | [模型C] | [作用说明] | 3-5分钟 |

💡 组合优势：[说明为什么这几个模型组合使用效果更好]

你可以：
- 输入 "开始" 按顺序引导
- 输入 "只用[模型A]" 单独使用某个模型
- 输入 /skip 跳过组合，使用标准GROW流程
```

### 3.2 组合引导流程

在标准GROW流程中嵌入组合模型：

```
Phase 0: 问题识别
  ↓
  └─→ 检测是否需要组合推荐
       ├─ 是 → 推荐组合，用户确认
       └─ 否 → 标准单模型引导

Phase 1: G阶段（目标）
  ↓
Phase 2: R阶段（现状）
  ↓
  └─→ 【组合第1个模型在此阶段嵌入】
       例如：根因分析（5Why）嵌入R阶段

Phase 3: O阶段（选项）
  ↓
  └─→ 【组合第2个模型在此阶段嵌入】
       例如：飞轮效应嵌入O阶段

Phase 4: W阶段（行动）
  ↓
  └─→ 【组合第3个模型在此阶段嵌入】
       例如：确认偏误嵌入W阶段作为验证

Phase 5: 输出交付
  └─→ 【组合效果评估】
       评估各模型的贡献度和组合协同效果
```

### 3.3 组合嵌入位置映射

| GROW阶段 | 适合嵌入的模型类型 | 示例 |
|---------|-----------------|------|
| R阶段 | 分析型、挖掘型 | 根因分析、第一性原理、5W1H |
| O阶段 | 拓展型、评估型 | 二阶思维、决策矩阵、横向思维 |
| W阶段 | 验证型、行动型 | 确认偏误、框架效应、SMART |

### 3.4 组合进度提示

使用组合时，进度提示格式升级：

```
📊 当前进度：R阶段 - 深度诊断组合（1/3）
  📌 当前模型：根因分析（5Why）
  ⏭ 下一个模型：飞轮效应（在O阶段启动）
```

## 四、组合效果评估

### 4.1 单模型贡献度评估

每个模型使用后，评估其对问题解决的贡献：

| 评估维度 | 评分标准 |
|---------|---------|
| **新洞察** | 这个模型是否带来了之前没想到的视角？（1-5分） |
| **实用性** | 这个模型的输出是否可以直接用于行动？（1-5分） |
| **关联度** | 这个模型与问题的相关程度如何？（1-5分） |
| **易用性** | 这个模型的使用过程是否顺畅？（1-5分） |

### 4.2 组合协同效果评估

评估多个模型组合使用后的整体效果：

| 评估维度 | 评分标准 |
|---------|---------|
| **1+1>2效应** | 组合使用是否比单独使用效果更好？（1-5分） |
| **逻辑连贯** | 模型之间的衔接是否自然流畅？（1-5分） |
| **结论完整** | 组合分析是否覆盖了问题的多个方面？（1-5分） |
| **时间效率** | 组合分析的时间投入是否值得？（1-5分） |

### 4.3 组合效果反馈话术

```
## 🔗 组合效果回顾

本次使用了【深度诊断】组合，效果评估：

| 模型 | 贡献度 | 关键产出 |
|-----|-------|---------|
```
