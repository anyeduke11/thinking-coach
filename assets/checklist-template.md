# 检查清单模板

> 使用说明：在汇报/执行前，逐项检查确认

---

## 一、汇报前检查清单

### 数据准备

| 检查项 | 标准 | 是否完成？ |
|-------|------|-----------|
| 核心数据准确 | 数据来源可靠，计算正确 | ☐ |
| 同比/环比计算正确 | 时间范围一致，口径统一 | ☐ |
| 趋势描述准确 | 有数据支撑，无主观臆断 | ☐ |
| 数据可视化准备 | 图表清晰，重点突出 | ☐ |

### 原因分析

| 检查项 | 标准 | 是否完成？ |
|-------|------|-----------|
| 根因分析到位 | 追问到第4-5层 | ☐ |
| 原因归类清晰 | 区分内外，标注可改进 | ☐ |
| 不甩锅 | 聚焦内部问题 | ☐ |
| 有数据支撑 | 关键原因有证据 | ☐ |

### 改进方案

| 检查项 | 标准 | 是否完成？ |
|-------|------|-----------|
| 方案具体 | 有明确动作，不空泛 | ☐ |
| 时间节点明确 | 有具体日期 | ☐ |
| 责任人明确 | 谁做什么，清晰 | ☐ |
| 需要支持明确 | 具体到资源/决策/协调 | ☐ |
| 预期务实 | 不过度承诺 | ☐ |

### 话术准备

| 检查项 | 标准 | 是否完成？ |
|-------|------|-----------|
| 开场话术熟练 | 能自然说出 | ☐ |
| 讲原因话术熟练 | 能自然说出 | ☐ |
| 讲方案话术熟练 | 能自然说出 | ☐ |
| 结尾话术熟练 | 能自然说出 | ☐ |
| 追问回答准备 | 预判问题有答案 | ☐ |
