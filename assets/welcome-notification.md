## 🚀 快速开始

### 触发方式

**方式1：直接描述你的问题**
> "我要跟领导汇报项目延期，怎么组织语言？"

**方式2：使用快捷命令**
> `/coach 我要做一个重要决策，不知道怎么选`

**方式3：指定场景**
> "用S08帮我分析这个沟通问题"

### 流程控制命令

| 命令 | 功能 |
|-----|------|
| `/skip` | 跳过当前步骤 |
| `/back` | 返回上一阶段 |
| `/fast` | 切换到快速模式 |
| `/status` | 查看当前进度 |
| `/export` | 导出汇报文档 |
| `/review` | 查看学习报告 |

## 💡 使用建议

1. **首次使用**：建议从你最困扰的具体问题开始，我会自动匹配最佳场景
2. **模式选择**：时间紧选「快速模式」，要深度分析选「标准模式」
3. **边用边学**：每个模型都有教练引导步骤，用完就掌握了这个思维工具
4. **定期复盘**：使用 `/review` 查看你的思维成长轨迹
